# Adversarial Failure Analysis
Revision0.1 • named periods anchor mechanisms only; numeric scenarios are synthetic, not historical backtests.

| Scenario / attack | Failure channel | Required diagnostic / unresolved consequence |
|---|---|---|
| 1970s-style inflation | Cash/bill real returns lag target; roll may not keep up | Target+15% branch; persistent negative-real-carry exhaustion; WP1E funding dependency |
| Rapid disinflation | Lagged liabilities and rates evolve at different speeds | +2% target with different asset returns; no assumed immediate fall in lagged target |
| Volcker-style tightening | Nominal/real yield rise despite inflation | Joint +10% target and asset loss; no claim actual TIPS existed in1979 |
| Sharp real-yield increase | Long TIPS sale losses overwhelm accretion | ±100/300/500bp exact zero-coupon diagnostic, full pricing later |
| Treasury-duration loss | Nominal long exposure is not bill-like | Maturity/key-rate stress; prohibit hiding longer exposure in a 'Treasury' label |
| TIPS real-rate drawdown | Indexed principal growth with falling quote | Track asset factor independently of target |
| COVID-style liquidity shock | Dealers constrained; spreads/size access break | Cash1/bill.99/TIPS.92 branch plus separate incremental sale-cost test |
| 2008-style stress | TIPS liquidity discount/counterparty distress | Target-.02/bill1.01/TIPS.85; avoid duplicating price/liquidity shock |
| Redemption surge | Cash depleted, early exits impose losses | Cumulative demand curve and deadline gap; no chosen run remedy |
| Inflation plus liquidity stress | Assets fall while indexed obligations rise | Common120/100 B buffer becomes-1.24 |
| Treasury-market dysfunction | 'Safe' securities not executable by deadline | Reduce bids, delay settlement; no Fed backstop assumption |
| Repo counterparty failure | Margin gap, closeout stay and collateral sale |102 collateral against100,5% fall+1%cost gives95.931; zero before legal access |
| Custodian impairment | Title may survive while cash inaccessible | Largest-group block; account diversification not same as service independence |
| Index impaired, assets liquid | Apparent coverage masks failed promise | Flag reference only; Q023 blocks activation, no surplus entitlement inferred |
| Reserve impaired, index normal | Good CPI cannot authenticate assets | Zero eligible credit for unverified/stale positions; gross claims remain |
| Fixed claims, rising T | Qfix lags indexed face; holder loses index exposure |80indexed+20fixed atT1.15 =112 versus115 fully indexed; terms unselected |
| Indexed claims, rising T | Accepted queue continues increasing |100indexed at1.15=115; funding deadline and price must agree |
| Deflation plus fixed claims | Qfix prevents full liability relief |80*.90+20=92 versus90; assess nominal matching branch |
| Long-duration TIPS mismatch | Maturity protection cannot fund early exit |5/10-year sensitivities and forced-sale tests |
| Forced liquidation before maturity | Purchase price/floor not recovered | Sale proceeds and remaining unpaid face separately retained |
| Asset double count / fake capital | Receivable+collateral or A+equity fabricates backing | Unique asset identity, disjoint encumbrance inventory, A-L-O residual |
| Quote manipulation / stale data | Optimistic matrix marks justify phantom capacity | Authentication/freshness exceptions; later oracle design remains open |
| AP/timing adverse selection | Sophisticated actors exit ahead of known target/price changes | WP1F needed; no AP permission or fee/gate invented |
| Hidden issuer liabilities | Deposits, taxes, costs, setoff omitted | Completeness false means undetermined aggregate; no zero default |
| Alternative-asset tail correlation | 'Diversifier' sells off with run | Adverse additive tail tests and no borrowed correlation benefit |

Historical anchors: [S03/S04/S07/S08](11-sources.md). They establish plausible failure mechanisms, not the scenario magnitudes. TIPS began1997, so1970s/Volcker comparisons are counterfactual regime analogues. No fitted probabilities, modern-real-rate historical reconstruction or full Phase2 environment is claimed.

Recommended response to failed diagnostic is to record the shortfall/unknown and require review, not to erase liability, automatically suspend legal rights, mint unbacked assets, change the benchmark, assume recapitalization or silently approve another package. Q023 and Q025 remain OPEN.
